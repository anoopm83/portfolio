# Anoop Mangalassery — Portfolio

Personal portfolio: a Product Manager who takes products from a problem worth
solving to a working app. Showcases five products built end to end — Marg AI,
Encore, TrueCost, DhanIQ, and a Vendor Pre-Onboarding flow.

Plain HTML, CSS and vanilla JavaScript. No build step — open `index.html` in a
browser, or view it live via GitHub Pages.

## Files
- `index.html` — the page
- `styles.css` — the styles
- `assets/` — product screenshots
- `photo.jpg`, `resume.pdf` — photo and résumé
